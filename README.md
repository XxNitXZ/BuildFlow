
# BuildFlow

BuildFlow is a full-stack job discovery and application tracking platform.

## Features (planned)
- Follow companies and discover their latest job openings
- Search and filter jobs by location, technology and remote work
- Save interesting jobs
- Track job applications
- Receive notifications about new opportunities

## Tech Stack
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Java, Spring Boot, Spring Data JPA
- Database: PostgreSQL
- Infrastructure: Docker and Docker Compose
- Testing: JUnit, Mockito, Playwright

Under development.
